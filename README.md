# Texas Biryani House - Premium Cloud Kitchen Website

A premium website for Texas Biryani House featuring high-quality food images, modern design, and automated email order system.

## 🌟 Premium Features

### Visual Design
- **Professional Food Photography**: Appetizing images for all menu items
- **Modern UI**: Card-based layouts with smooth animations and hover effects
- **Premium Typography**: Elegant fonts (Playfair Display, Cormorant Garamond)
- **Responsive**: Optimized for all devices

### Order System
- **Email Integration**: Orders automatically sent to prasad.chetti@gmail.com
- **Real-time Pricing**: Live order summary with total calculation
- **Progress Tracking**: Visual progress bar as form is filled
- **Validation**: Ensures complete and accurate orders

## 📧 Email Setup (IMPORTANT)

**First submission requires verification:**
1. Submit a test order
2. Check prasad.chetti@gmail.com for verification email from FormSubmit
3. Click verification link
4. All future orders will deliver automatically

## 🚀 Quick Start

### GitHub Pages (Recommended)
1. Go to Settings → Pages
2. Select `copilot/build-restaurant-website` branch
3. Save
4. Live at: `https://vardhan-225.github.io/TBH/`

### Local
Open `index.html` in any browser (no server needed)
